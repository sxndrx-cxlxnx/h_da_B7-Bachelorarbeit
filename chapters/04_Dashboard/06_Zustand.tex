\section{Zustandsanalyse auf Grundlage der identifizierten Anforderungen}
\label{ch:Dashboard:sec:Anforderungen_Auswertung}

Das Dash\-board ermöglicht es dem Nutzer, die Ergebnisse des Testpools übersichtlich, vollständig und tagesaktuell anzuzeigen. Dabei wurden zwei Dash\-boards implementiert, welche die tägliche Nutzung der Entwicklungsumgebung von der veröffentlichten Umgebung unterscheidet. Beide Dash\-boards ermöglichen einen vollständigen Zugriff auf alle Systeme, welche an der Erzeugung der Ergebnisse des Testpools beteiligt sind.

Das neue System kann die Anzahl der Anwendungsfälle, welche im alten System mit je einer Oberfläche abgedeckt wurden, nicht reduzieren. Stattdessen trägt die Farbgestaltung, welche den Fehlerfall hervorhebt, zur Übersichtlichkeit bei. Zeigen alle Werte eine graue Null an, so ist der Green Day erreicht und die genauen Ergebnisse der einzelnen Anwendungsfälle müssen nicht weiter betrachtet werden.

Die übernommene Kategorisierung der Ergebnisse gibt dem Nutzer die gleiche gewohnte Struktur vor, wodurch er im Fehlerfall die Stelle im alten System eindeutig identifizieren kann. Anhand der Verlinkung zur entsprechenden Oberfläche des alten Systems kann schließlich auf die Detailausgabe zugegriffen werden.

\noindent
Hierbei ist darauf hinzuweisen, dass nicht ausschließlich weitere Empfehlungen umgesetzt werden konnten. Es ist nicht gelungen, im Rahmen des Prinzips der Selbstbeschreibungsfähigkeit, die \glqq Informationen so darstellen, dass eindeutig ersichtlich ist, welche Benutzungsschnittstellen-Elemente interaktiv und welche nicht interaktiv sind\grqq{} \cite{DIN_EN_ISO_9241-110}. Während das alte System dies teilweise ermöglicht, wirken die Verlinkungen durch den Darkmode unscheinbar.

Im Rahmen des Prinzips der Erwartungskonformität konnten \glqq Informationen auf unterschiedlichen Gerätearten und Anzeigegrößen [nicht] angemessen [dargestellt]\grqq{} \cite{DIN_EN_ISO_9241-110} werden. Die Layouts des alten Systems sehen auf verschiedenen Bildschirmgrößen gleich aus, dadurch entsprechend angemessen, um sich im System zurechtzufinden. Das neue System ist anhand eines Rasters aufgebaut, welches sich beim Verändern der Bildschirmgröße oder der Seitenverhältnisse verschieben kann. 

Stattdessen kann das neue System sich jedoch im Bereich der Benutzerbindung beweisen, da es so ausgelegt ist, \glqq dass es Benutzererfordernisse antizipiert, deren sich der Benutzer möglicherweise gar nicht bewusst ist\grqq{} \cite{DIN_EN_ISO_9241-110}. Es liefert zusätzliche Informationen, welche zum Monitoring selbst nicht benötigt werden, jedoch beim Nutzer zu einem fundierten Hintergrundwissen über das System beitragen.
